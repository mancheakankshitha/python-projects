# Credit Card Fraud Detection

## Overview

This project uses Machine Learning to detect fraudulent credit card transactions.

## Features

* Predicts whether a transaction is fraudulent or legitimate
* Trained machine learning model saved as a .pkl file
* Easy-to-use Python application

## Files

* app.py – Main application
* credit_card_fraud_model.pkl – Trained model
* requirements.txt – Required Python libraries

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn

## Installation

pip install -r requirements.txt

## Run

python app.py
